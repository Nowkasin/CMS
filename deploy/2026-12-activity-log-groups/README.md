# สิทธิ์เมนู "ประวัติการใช้งาน" ตามกลุ่ม

ให้สิทธิ์เมนู key `activity_log_view` (หน้า `/log/`) กับกลุ่มทดสอบ 2 กลุ่ม ไม่แก้ `Sysmenu` ไม่แก้ Schema

- **ทดสอบ หลังบ้านตั้งหนี้ CMS, SAP** (`00B67BB6-1982-400F-BA50-33CF8FA36D3E`)
- **ทดสอบ หน้าบ้านสร้างสัญญา** (`31200B53-36EC-47A1-88F2-4463A597C0F9`)

ผู้ดูแลระบบ ( Admin ) มีสิทธิ์เมนูนี้อยู่แล้ว สคริปต์นี้เพิ่มสิทธิ์อย่างเดียว ไม่ปิดสิทธิ์กลุ่มอื่น

## ใครเห็นอะไรในหน้าประวัติการใช้งาน (กรองในโค้ด ไม่ใช่ในฐานข้อมูล)

- **ผู้ดูแลระบบ** (`CMS_ADMIN_GROUP_IDS`) เห็นทุกเหตุการณ์ รวมเข้า/ออกระบบ และดูในมุมมองกลุ่ม
- **คนอื่น** เห็นเฉพาะเหตุการณ์ของเมนูที่กลุ่มตัวเองมีสิทธิ์ (ของทุกคนในเมนูนั้น)
  ตาม `ACTION_PERMISSIONS` ใน `meters/services/activity_log.py` เช่น กลุ่มที่มีแค่เมนูใบแจ้งหนี้
  เห็นแค่ "พิมพ์ใบแจ้งหนี้" -- ไม่เห็นเข้า/ออกระบบของคนอื่น
- ผู้ดูแลที่กำลัง "ดูในมุมมองกลุ่ม" เห็นแบบกลุ่มนั้น

## ไฟล์

1. `01_apply_activity_log_groups.sql` — ให้สิทธิ์ภายใน Transaction รันซ้ำได้
2. `02_rollback_activity_log_groups.sql` — ปิดสิทธิ์ (IsActive = 0) ของ 2 กลุ่มนี้ ไม่ลบแถว ไม่แตะเมนูหลัก

## ลำดับติดตั้ง

1. ต้องมีเมนูหลัก `water_electric_new` และเมนู `activity_log_view` แล้ว (`deploy/2026-11-cms-menu`)
2. Deploy โค้ดรุ่นที่กรอง log ตามกลุ่มก่อน -- ถ้ารันสคริปต์ก่อน กลุ่มทดสอบจะเห็น log ทั้งระบบ
3. ตรวจ GroupId บน PRD ว่าตรงกับ DEV
4. รัน `01_apply_activity_log_groups.sql`
5. ผู้ใช้เห็นเมนูภายใน 10 นาที (`CMS_ACCESS_REFRESH_SECONDS`) หรือออกจากระบบแล้วเข้าใหม่

## ประวัติการรัน

- 2026-11-26 DEV (`DBDEV` / `SWU_contract`) — รันแล้ว ทั้ง 2 กลุ่มได้สิทธิ์
- PRD — ยังไม่ได้รัน

# สิทธิ์ภาพรวมพื้นที่เช่า

ยังไม่ได้รัน SQL กับฐานข้อมูล สคริปต์เริ่มต้นเป็น PREVIEW

1. ตรวจฐานข้อมูลและกรอก URL จริงใน 01_menu.sql โดย path ของแอปคือ dashboard/spaces/ (เพิ่ม prefix เช่น /cms/ ตามเครื่อง)
2. รัน PREVIEW เพื่อตรวจ แล้วเปลี่ยนเป็น APPLY เพื่อเพิ่มเมนู ไม่บังคับเลข Identity และไม่แก้เมนูเดิม
3. ในหน้ากำหนดสิทธิ์ของ K2 เลือก “ภาพรวมพื้นที่เช่า” ให้กลุ่มที่ต้องการ พร้อมสิทธิ์เมนูหลัก CMS เดิม
4. ออกจากระบบและเข้าสู่ระบบใหม่เพื่อโหลดสิทธิ์

Key ใหม่คือ space_dashboard_view แยกจาก dashboard_view และ space_profile_view
ParentMenu ในฐานข้อมูลยังอยู่ใต้ CMS เพื่อให้กลไกอ่านสิทธิ์เดิมรองรับ ส่วน Sidebar จัดเป็นเมนูย่อยใต้ “แดชบอร์ด” และแสดงเฉพาะรายการที่มีสิทธิ์

ข้อมูลมาจาก service รอบพื้นที่เดิม: รอบเปิดใช้ Stored Procedure และ Input รอบปิดใช้ Snapshot
แนวโน้มรายปีใช้เฉพาะ Snapshot ของรอบ CLOSED และรอบที่กำลังจัดทำ
ชื่อสถานที่ตั้ง/อาคารอ่านทะเบียนปัจจุบัน จึงอาจเปลี่ยนชื่อในรายงานเก่าได้ แต่ยอดและสถานะมาจากรอบนั้น
สถานะ “เช่าอยู่” กับ “ว่าง” นับตรงตามข้อความ สถานะอื่นแยกไว้ ไม่เหมารวมเป็นว่าง

# ติดตั้งเมนู "ใบแจ้งหนี้"

เพิ่มเมนูย่อย key `invoice_print` (หน้า `/invoice/`) ใต้ระบบ `water_electric_new`
และให้สิทธิ์ 3 กลุ่ม ไม่สร้างหรือแก้ Schema

- **ทดสอบ หลังบ้านตั้งหนี้ CMS, SAP** (`00B67BB6-1982-400F-BA50-33CF8FA36D3E`)
- **ทดสอบ หน้าบ้านสร้างสัญญา** (`31200B53-36EC-47A1-88F2-4463A597C0F9`)
- **ผู้ดูแลระบบ ( Admin )** (`9B148353-6383-40D7-B3B8-F04FC8C5A4C5`)

ไม่ให้กลุ่ม Cashier ID ทุกกลุ่ม (Cashier ID, Cashier ID Approve, Cashier ID Approve ส่วนการคลัง)
และไม่ให้เจ้าหน้าที่บัญชี (ผู้ใช้กำหนด 2026-11-24) -- `@Groups` เป็นรายการทั้งหมด
กลุ่มที่เคยได้สิทธิ์เมนูนี้แต่ไม่อยู่ในรายการ (เช่น Cashier ID Approve ส่วนการคลัง จากสคริปต์รุ่นก่อน)
จะถูกปิดสิทธิ์เมนูใบแจ้งหนี้ (IsActive = 0) แต่ไม่แตะสิทธิ์เมนูหลัก `water_electric_new`

หน้าใบแจ้งหนี้อ่านข้อมูลอย่างเดียว (ดู `meters/services/invoice.py`) และเรียก
SP เดิม `sp_6000_Contact_Doc_invoice` (ตัวเดียวกับที่ฟอร์ม K2 FRM_4019_Invoice_CMS ใช้) เพื่อข้อความรายการ

## ไฟล์

1. `01_apply_invoice_menu.sql` — เพิ่ม/ปรับเมนู และให้สิทธิ์กลุ่มภายใน Transaction
2. `02_rollback_invoice_menu.sql` — ปิดเมนูและสิทธิ์ของเมนูนี้ โดยไม่ลบแถว

## ลำดับติดตั้ง

1. ต้องติดตั้งชุด `deploy/2026-11-cms-menu` แล้ว (มีเมนูหลัก `water_electric_new`)
2. แก้ `@CmsBaseUrl` ใน `01_apply_invoice_menu.sql` ให้ตรงกับ URL จริง
3. ถ้ากลุ่มอื่นต้องใช้ด้วย เพิ่ม `GroupId` ในตาราง `@Groups`
4. Deploy โค้ดรุ่นที่มีหน้า `/invoice/` แล้วรัน `collectstatic`
5. รัน `01_apply_invoice_menu.sql`
6. ผู้ใช้ในกลุ่มจะเห็นเมนูภายใน 10 นาที (CMS ดึงสิทธิ์ใหม่ทุก `CMS_ACCESS_REFRESH_SECONDS`)
   หรือออกจากระบบแล้วเข้าใหม่

## ประวัติการรัน

- DEV (`DBDEV` / `SWU_contract`, menuId 91) — รุ่นแรกให้ Cashier ID Approve ส่วนการคลัง + Admin
- 2026-11-24 DEV — รันรุ่นปัจจุบัน: ให้ 2 กลุ่มทดสอบ + Admin, ปิดสิทธิ์เมนูใบแจ้งหนี้ของ
  Cashier ID Approve ส่วนการคลัง และปิดสิทธิ์เมนูหลัก `water_electric_new` ของกลุ่มนี้ด้วยมือ
  (สิทธิ์ที่รุ่นแรกเพิ่มให้ กลุ่มนี้ไม่มีเมนูอื่นใน CMS)
- PRD — ยังไม่ได้รัน ถ้ารันรุ่นปัจจุบันครั้งแรกบน PRD จะไม่มีสิทธิ์ของกลุ่ม Cashier ให้ต้องปิด
